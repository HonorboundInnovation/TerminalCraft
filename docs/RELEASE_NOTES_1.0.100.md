# TerminalCraft 1.0.100 — disk drive and rack blade models

The disk drive now has a recessed front panel and casing rails, using its
existing textures. Selection and collision follow that cabinet in all four
horizontal facings. Structure rotation and mirroring now rotate its front.
Disk insertion, ejection, mounting and saved contents are unchanged.

Loose server and router blades share a centered 3D cartridge with a raised
front panel and rear connector. Each uses the same front artwork as its
installed rack module. All existing texture files are preserved.

Includes 1.0.99's responsive terminal/editor layout. This is a development
build; live UI and full visual catalog acceptance remain open, along with
the integration, multiplayer/recovery and performance release gates.
