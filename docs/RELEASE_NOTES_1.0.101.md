# TerminalCraft 1.0.101 — guide and display configuration

Guide illustrations now scale the complete image instead of cropping it.
Chapter navigation fits narrow windows, and chapter search survives resizing.
Header and footer text leave room for their neighboring controls.

Display-link channel drafts survive focus changes and resizing. Apply uses
the existing channel formatting rules; unedited fields still follow server
updates. Display configuration fits an ordinary 320-wide GUI, and long cable
connection lists wrap within the panel.

Includes the disk-drive and rack-blade models from 1.0.100. Existing textures,
guide content, network protocols and server authorization are unchanged.

Development build: live UI/catalog review and the remaining integration,
multiplayer/recovery and performance release gates are still open.
