# TerminalCraft 1.0.102 — monitor and PLC interaction fixes

Monitor selection and collision now follow the visible thin panel in every
horizontal direction. Structure rotation and mirroring rotate its facing.

The PLC source editor no longer extends beneath the wide live-watch panel.
Compact headers leave room for the mode shortcut; long status messages fit
the footer and show their full text on hover. Empty ladder guidance wraps
within the canvas, and the ladder hint no longer overlaps the status footer.

Includes the previous guide, display-configuration and model improvements.
Textures, PLC execution and monitor touch-coordinate handling are unchanged.

Development build. The owner is taking over in-game testing. Remaining
integration/feature requirements are still tracked in the completion plan;
this is not a claim that all release work is finished.
