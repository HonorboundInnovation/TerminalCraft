# TerminalCraft 1.0.48

Build 48 adds an in-game, comprehensive TerminalCraft field manual designed for learning and
commissioning the mod without leaving Minecraft.

## TerminalCraft Guide item

Craft the guide with a Book in the center, Paper on its left and right, and Redstone above and below.
Right-click it to open the reader. It is also available in the TerminalCraft creative tab.

The reader provides:

- a full chapter index with mouse and previous/next navigation;
- wheel, arrow, Home/End, and Page Up/Page Down scrolling;
- Ctrl+F full-text chapter search;
- styled headings, paragraphs, lists, warnings, tables, and source-code blocks;
- a responsive non-pausing interface that works offline with no documentation dependency.

## Comprehensive content

- The complete TerminalCraft Guide covers installation, blocks, crafting, Bash terminal commands,
  the virtual filesystem, shell scripting, sample scripts, turtles, monitors, redstone, bundled I/O,
  PLCs, disks, RedNet, DNS, devices, storage, events, server jobs, authorization, integrations,
  configuration, security limits, troubleshooting, and Bash compatibility differences.
- The complete Advanced Script Cookbook adds failure-aware tunneling, storage and crafting workflows,
  exact transfers, network commissioning, event watches, rack jobs, deployment, and incident capture.
- Every built-in general and Create PLC template is generated into the book from the executable
  template catalog, including its description and exact compile-tested source.
- The PLC manual now documents the complete instruction set, scan lifecycle, digital/analog I/O,
  expressions, timers, counters, latches, MOVE, SCALE, PID, fail-safe design, and commissioning.
