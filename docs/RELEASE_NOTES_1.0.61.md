# TerminalCraft 1.0.61 — Single-Cable RedPower Routing

TerminalCraft 1.0.61 removes the active matrix/grid experiment from both ordinary cable families.

- Each block face accepts one centered Shielded Red Alloy Wire or one centered Network Cable.
- Compatible same-color cables automatically connect across neighboring blocks and around supported
  corners, with automatic turns and junctions.
- Red Alloy automatically connects to vanilla-redstone endpoints and bundled Red Alloy breakouts.
- Network Cable automatically connects to wired devices, modems, and bundled network trunks.
- The placement overlay is one centered marker; there are no point, row, lane, or matrix controls.
- Existing 1.0.58-1.0.60 cable matrices are collapsed to one retained cable per occupied face.
