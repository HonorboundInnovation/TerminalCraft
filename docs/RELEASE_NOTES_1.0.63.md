# TerminalCraft 1.0.63 — Solid Cable Colors and Restored Unshielded Wire

TerminalCraft 1.0.63 replaces the patterned surface-cable artwork with clean dye-tinted textures and
restores the original Unshielded Red Alloy Wire as a first-class survival and creative item.

- Shielded Red Alloy Wire and colored Network Cable now render as solid assigned colors in the world.
- Their inventory icons use clean single-color silhouettes rather than the old glowing dot artwork.
- The Red Alloy crafting recipe produces twelve Unshielded Red Alloy Wires.
- Dyeing an unshielded or already shielded wire produces the selected Shielded Red Alloy color.
- Network Cable remains craftable in batches of eight and can be dyed to all sixteen colors.
- Creative tabs contain the unshielded wire plus all sixteen shielded wire and Network Cable colors.
- Insulation is persisted per placed face. Existing colored saves remain shielded.
- Unshielded wire carries ordinary redstone and may join colored Red Alloy, but it cannot enter any
  Bundled Red Alloy channel. A matching colored shielded breakout is still required.
- The new craftable Red Alloy Capacitor restores any nonzero input to strength 15 on the directly
  opposing face. Its six independent straight-through directions extend long Red Alloy runs without
  sideways signal leakage.
- Red Alloy Wire, Network Cable, Bundled Red Alloy Cable, and Bundled Network Cable now have
  face-oriented half-block selection shapes: horizontal slab halves on floors/ceilings and vertical
  wall halves on walls. Multipart cable blocks combine the occupied face halves while retaining
  their thin rendered models.

Artifact: `terminalcraft-1.20.1-47.4.10-1.0.63.jar`
