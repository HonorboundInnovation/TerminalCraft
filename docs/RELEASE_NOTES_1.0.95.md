# TerminalCraft 1.0.95 — cabinet model pass

Server racks now have recessed bays, frame rails, vented sides and solid server
and router blade fronts contained inside the cabinet. PLCs retain their approved
front artwork with vented casing and a selection/collision shape matching the
inset cabinet in all four facings. Existing texture files are unchanged.

This includes 1.0.94's features and fixes. No registry IDs, network protocol, or
saved-data formats change in this model pass. Remaining integration, multiplayer,
recovery, full-catalog visual and performance qualification is still open.

The development checks also now cover main Create and Mekanism controls and a
Storage Drawers-to-Sophisticated chest transfer. Optional-mod test profiles do
not bundle or require those mods in the production artifact.

This is a development build, not a completed release candidate. Packaging and
rendered-review results are tracked in the completion evidence and release plan.
