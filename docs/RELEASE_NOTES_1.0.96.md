# TerminalCraft 1.0.96 — storage and Materializer models

NAS cabinets now show eight raised drive bays. Refined Storage and AE2 bridges
have solid front panels and vented casings. These three machines now face the
player when placed and support rotation and mirroring; existing blocks default
to north. Facing affects appearance, not network attachment sides or access.

The Materializer has an open frame that exposes its central element, with
matching selection/collision geometry. Existing approved texture files are
unchanged across all these models. Storage, crafting and permission behavior
is unchanged; AE2 writes remain disabled pending the access-policy decision.

Includes 1.0.95's rack and PLC changes. This remains a development build:
full-catalog visual approval, integration, multiplayer, recovery, performance
and final release qualification are not complete. Verification and rendered
review results are recorded in the release plan and completion evidence.
