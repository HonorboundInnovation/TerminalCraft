# TerminalCraft 1.0.98 — SSD presentation and machine targeting

The three SSD tiers have solid cartridges with separate, fully mapped label
faces and clearer inventory/item-frame transforms. Their original textures
and tier identities are unchanged.

Turtle, modem, NAS and both storage bridges now use selection/collision shapes
matching their visible models. Storage cabinet shapes follow their four facing
directions. Movement, networking, storage capacities, access rules, registry
IDs and data formats are unchanged.

Includes the preceding model passes. This is a development build, not a final
release candidate. Remaining catalog, UI, integration, multiplayer, recovery
and performance qualification is tracked in the release plan.
