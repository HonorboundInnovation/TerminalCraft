# TerminalCraft 1.0.99 — responsive terminal and editor

Terminal and editor panels now fit ordinary scaled Minecraft windows.
Compact terminals omit the optional status sidebar to leave room for commands
and output. Output rows follow the available height; full-sized panels keep
the existing status rail and eighteen rows.

Page Up/Down scroll a viewport page with one context row instead of a single
line. Command entry, history, storage, editor saving and networking protocols
are unchanged. Includes prior model and interaction improvements.

This is a development build. Remaining UI, catalog, integration, multiplayer,
recovery and performance acceptance is tracked in the release plan.
